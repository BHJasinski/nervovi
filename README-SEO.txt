NERVOVI - PUBLIKACJA I INDEKSACJA

1. Wgraj wszystkie pliki ZIP do głównego katalogu repozytorium GitHub Pages (również folder assets). Nie usuwaj istniejącego pliku CNAME.
2. Upewnij się, że pod https://nervovi.org/ działa strona, pod https://nervovi.org/favicon.ico ikona, a pod https://nervovi.org/sitemap.xml mapa.
3. W Google Search Console zweryfikuj domenę nervovi.org, prześlij sitemap.xml i w narzędziu Sprawdzenie adresu URL poproś o indeksowanie strony głównej.
4. Zadbaj o przekierowanie www.nervovi.org na nervovi.org albo skonfiguruj jedną główną wersję adresu.
5. Publikuj autorskie i pomocne materiały o rozwiązaniach AI oraz dostępności, najlepiej na osobnych podstronach. To ważniejsze dla widoczności organicznej niż same metatagi.
6. Po publikacji przetestuj w PageSpeed Insights, Rich Results Test i Lighthouse (SEO / Accessibility).

Nie da się zagwarantować pozycji ani czasu indeksacji w Google.
