NERVOVI – STRONA DO GITHUB PAGES

1. Otwórz repozytorium GitHub, z którego publikujesz nervovi.org.
2. W katalogu głównym repozytorium prześlij plik index.html oraz folder assets wraz z oboma plikami:
   - assets/logo-nervovi.svg
   - assets/magda-bartek-nervovi.png
3. Zatwierdź zmiany przez Commit changes.
4. Nie zmieniaj istniejącego pliku CNAME ani ustawień domeny w GitHub Pages.
5. Jeżeli GitHub Pages publikuje z innego folderu lub gałęzi, prześlij pliki do tego właśnie katalogu publikacji.
6. Sprawdź stronę na telefonie i komputerze, działanie menu, powiększania tekstu i wysokiego kontrastu.

Ważne:
- Stan prawny fundacji opisano jako 'inicjatywa przygotowująca powołanie fundacji', bez sugerowania wpisu do KRS.
- Treści AI przedstawiono jako kierunki prac, nie jako już działające produkty.
- Logo jest oryginalnym dostarczonym SVG z poprawionym kadrowaniem.
- Nie ma zależności od zewnętrznych skryptów ani bibliotek.
- Implementacja uwzględnia podstawowe praktyki dostępności, lecz nie jest równoznaczna z formalnym audytem WCAG 2.2 AA.
